### 🕹️ What's Inside?

- 🖱️ **Draggable Window Manager** — Stack, minimize, close
- 🎮 **Space Duel Arcade** — Full shoot 'em up game
- 🌧️ **Matrix Code Rain** — Controllable speed & color
- 📊 **Oscilloscope Diagnostics** — Live sine wave CPU monitor
- 📄 **CV ATS Scanner** — Resume match scoring engine
- 💻 **Hacker CLI Terminal** — Type `help`, `neofetch`, `fortune`
- 🎨 **5 Neon Themes** — Cyberpunk, Matrix, Vaporwave, Amber, Cyan
- 📬 **Encrypted Mail Client** — Contact form simulator

</td>
<td width="50%">

### ⌨️ Controls

```
DESKTOP:
  Click icon    → Open window
  Drag titlebar → Move window
  [_] button    → Minimize
  [X] button    → Close

ARCADE (Space Duel):
  A / D         → Move ship
  SPACE         → Fire laser
  Click canvas  → Fire + move

CLI TERMINAL:
  help          → List commands
  neofetch      → System info
  fortune       → Random quote
  matrix        → Open rain app
  arcade        → Launch game
```
